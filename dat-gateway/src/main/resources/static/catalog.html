AI Agent Connection Guide

1 Cursor IDE 연동

1. Cursor 설정 창 열기 (Cmd/Ctrl + ,)

2. 사이드바에서 Features > MCP 메뉴로 이동

3. + Add New MCP Server를 클릭하고, 툴 카테고리의 [Copy SSE URL] 버튼으로 복사한 주소를 `SSE` 타입으로 붙여넣기 하세요.

2 Claude Desktop 연동

1. 아래 설정 파일을 텍스트 에디터로 엽니다:

Mac: ~/Library/Application Support/Claude/claude_desktop_config.json
Win: %APPDATA%\Claude\claude_desktop_config.json

2. 화면 우측 상단의 [Copy Client Config] 버튼을 누른 후, 복사된 JSON 코드를 이 파일 안에 그대로 붙여넣습니다.

3 커스텀 Python/Node Agent 연동

1. MCP 공식 SDK를 설치합니다. npm i @modelcontextprotocol/sdk

2. SSE Client Transport를 사용하여 복사한 카테고리별 URL로 연결합니다.
